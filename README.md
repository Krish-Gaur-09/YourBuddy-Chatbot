# YourBuddy Chatbot 🤖

YourBuddy is a simple rule-based chatbot built using Python.
It interacts with users through predefined responses and provides
a basic conversational experience.

## ✨ Features

- Greets users according to the time of day.
- Asks for the user's name.
- Responds to predefined messages.
- Provides simple conversational interactions.
- Exits the conversation when the user types "bye".

## 🛠️ Technologies Used

- Python
- DateTime Module

## ▶️ How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the Python file:
   python chatbot.py

## 🎯 Project Purpose

This project was created to practice Python fundamentals,
conditional statements, user input, and rule-based chatbot logic.
